# iotairclean

## Historisches netidee-Projekt

IoT Air Clean ist ein altes netidee-Projekt. Dieses Repository wird als historischer Projektstand archiviert und nicht mehr aktiv gewartet. Quellcode und Dokumentation bleiben zur Nachvollziehbarkeit erhalten.

Die enthaltenen Beispiele und Abhängigkeiten wurden nicht für heutige Laufzeitumgebungen geprüft. Eine Wiederinbetriebnahme erfordert eine technische Überprüfung und gegebenenfalls Anpassungen.
